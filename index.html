Cần cấu hình Firebase trước khi dùng

Trang này dùng Firebase Firestore (miễn phí) để nhiều người cùng xem/cập nhật kế hoạch theo thời gian thực mà không cần tự viết server. Hãy làm theo các bước sau rồi nạp lại trang:

  1. Vào firebase.google.com → tạo project mới (miễn phí).
  2. Trong project, bật Firestore Database (chọn chế độ Production hoặc Test).
  3. Vào Project settings → General → Your apps → Web app để lấy đoạn cấu hình (apiKey, projectId…).
  4. Mở file HTML này, tìm biến FIREBASE_CONFIG ở gần đầu thẻ <script> và dán cấu hình của bạn vào.
  5. Vào tab Rules của Firestore và đặt quyền đọc/ghi cho collection planner-workspaces (mẫu quy tắc có trong chú thích của file).

Sau khi lưu file và tải lại, trang sẽ hoạt động bình thường và có thể đưa lên GitHub Pages.
